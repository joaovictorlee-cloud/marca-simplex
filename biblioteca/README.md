# Biblioteca visual Simplex

Imagens, referências de estilo e ícones **aprovados** para uso em decks, PPTX,
artefatos, posts e documentos da Simplex. Gerada pela skill `simplex-imagens`;
consumida pela skill `simplex-marca`. Não edite à mão: este arquivo e o
`indice.json` são refeitos a cada publicação.

```bash
curl -s https://raw.githubusercontent.com/joaovictorlee-cloud/marca-simplex/main/biblioteca/indice.json
```

**Regras de uso**

- Busque aqui antes de gerar imagem ou desenhar icone. Reusar vale mais que ter o exato.
- Imagem com origem "gerada por IA": material para cliente que a use deve dizer isso.
- Nenhuma imagem daqui substitui logo, simbolo ou pattern oficial (pasta logos/).
- Texto nunca vem na imagem: entra por cima, em Gilroy, respeitando area_de_texto.
- Icone herda currentColor. Em PPTX use PNG gerado a partir do SVG.

Versão `2026.09.25.2005`.
